# Diseased

**A Unity game developed for the IGDA CPCC Chapter's 2026 Fall GameJam.**

## Play the Game

[Play Diseased on Unity Play](https://play.unity.com/en/games/17efc226-d9a9-4859-8cf5-b89621d71ea8/diseased)

Diseased is a collaborative game development project built during the IGDA CPCC Chapter's Fall 2026 GameJam. The project features interconnected gameplay systems involving player health, inventory management, crafting, NPC dialogue, item-based quests, and scene progression.

## About the Project

The game was developed by a team working under a limited GameJam timeframe. I served as the **primary programmer and gameplay systems developer**, implementing the majority of the game's code and integrating the different gameplay features into a functioning experience.

## My Contributions

I was responsible for the majority of the programming and backend implementation, including:

- **Player Movement:** Implemented player movement and control systems.
- **Health System:** Developed player health management and disease-related gameplay mechanics.
- **Inventory System:** Created item collection, inventory management, and item interaction functionality.
- **Crafting System:** Implemented recipes and item combinations with different effects.
- **NPC Dialogue:** Developed NPC interaction and dialogue functionality.
- **Quest System:** Created an item-based questline with progression tied to unique quest objects.
- **Unique Items:** Implemented custom item behaviors and effects.
- **Interactables:** Built the interaction framework for objects the player can use.
- **Scene Transitions:** Developed door interactions for transitioning between game scenes.
- **Persistent Game States:** Implemented persistent player, camera, and HUD states across scene changes.
- **System Integration:** Connected gameplay systems and resolved implementation issues throughout development.

Other team members primarily contributed the game's art, audio, and scene design.
